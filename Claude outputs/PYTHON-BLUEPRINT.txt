3. PHASES
--------------------------------------------------------------------------------
PHASE 0 — SETUP ...................................... 1 shaam
  Python 3.12+, venv, pip, VS Code + Python extension, ruff (format+lint),
  pytest. Bas. Koi bhari IDE nahi, koi course nahi khareedna.
  venv ka matlab: har project ke apne package, alag dabbe mein — composer
  jaisa, lekin folder ke andar.

PHASE 1 — PHP SE PYTHON TARJUMA ...................... 2-3 hafte
  Tutorial dekhne ke bajaye: jo cheez PHP mein aati hai, wo Python mein
  likho.
  SAB SE BEHTAR MASHQ: Zimal ka `ProductStatus` enum aur `Sku` class Python
  mein dobara likho. Logic pehle se aata hai, to poori mehnat SIRF Python
  par lagegi — koi naya domain sochna nahi parega.
    PHP backed enum        -> enum.StrEnum (Python 3.11+)
    final readonly class   -> @dataclass(frozen=True)
    constructor ke check   -> __post_init__
    throw InvalidArgument  -> raise ValueError
    match ($this)          -> match/case ya dict
    array_filter + closure -> list comprehension / filter()
    PHPUnit + DataProvider -> pytest + @pytest.mark.parametrize

PHASE 2 — LOGIC KI ROZANA MASHQ ...................... saath saath, hamesha
  Roz 20-30 minute, Phase 1 ke SAATH, na ke baad.
  Exercism ka Python track (muft, aasan se mushkil ki taraf).
  Qaida Q2: 20 minute akele, phir madad.
  Ye wo hissa hai jo waqai kami theek karta hai. Phase 1 zubaan sikhata
  hai; ye hissa LOGIC sikhata hai. Dono alag cheezein hain.

PHASE 3 — PANDAS / DATA ANALYSIS ..................... 4-6 hafte
  Yehi pul hai. Apne aap kaam ka hai, aur ML iske baghair nahi hota.
  Seekhne ki tartib: CSV parhna -> saaf karna -> groupby -> merge -> chart.
  ASLI data par karo, khilone par nahi. Apne hi kharche ya kamai ka CSV,
  ya UK ka open data. Jo sawaal ka jawab tumhein WAQAI chahiye, usi par.

PHASE 4 — ML, SIRF scikit-learn ...................... 6-8 hafte
  Deep learning se shuru NAHI. Tartib: regression -> classification ->
  evaluation.
  Aur sach ye hai: ML mein mushkil hissa code nahi hai, mushkil hissa ye
  janna hai ke model WAQAI acha hai ya nahi. Evaluation sab se zyada waqt
  maangta hai, aur tutorials usay sab se kam dete hain.

PHASE 5 — PHIR FAISLA ................................ abhi nahi
  Python web (FastAPI) ya gehri ML — ye faisla PHASE 4 KE BAAD hoga.
  Web aakhir mein isi liye hai ke web pehle se aata hai: usay naye zubaan
  mein dobara seekhna, list ki har cheez se KAM sikhayega. Baad mein tez
  pakad lega, bilkul isi liye ke wo aata hai.
